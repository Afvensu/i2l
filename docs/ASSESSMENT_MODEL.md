# Assessment Model — In the Dock

## Philosophy
The simulation is the assessment environment. Do not append a conventional quiz.

## Capability revealed
Can the learner recognise a procedural problem, intervene at the right moment, preserve the relevant record, advocate using the appropriate framework, reason about disputed evidence and carry professional consequences forward?

## Observable dimensions
1. Recognition — spots the relevant legal/procedural problem.
2. Intervention — chooses an appropriate professional response.
3. Completeness — recognises interconnected violations.
4. Documentation — creates a usable record.
5. Advocacy — constructs an appropriate bail/evidence submission.
6. Evidence reasoning — understands the source's inclusionary framework.
7. Timing — acts before opportunities are lost.
8. Professional judgement — avoids attractive but weaker shortcuts.
9. Sequential reasoning — uses earlier actions as later resources.

## Tracking
Store decision identity, beat reached, state changes, flags, custody status, record variant and ending. Avoid presenting raw numerical scores during play.

## Lapse taxonomy
Flags should identify the actual missed professional action and the beat where it occurred. E-02 feedback should be generated from the accumulated flags rather than from a generic failure message.

## Performance language
Use the source's formative categories: Expert Advocate, Developing Advocate, Learning the Ropes, Back to Chambers. Keep assessment tied to observed behaviour in the case.
